# Import Formats

The canonical V2 learning-card specification is now documented in the project root:

`IMPORT_FORMAT.md`

Recommended template:

`templates/learning-content-import-template.csv`

Legacy TXT/CSV/DOCX/XLSX vocabulary formats remain supported for backward compatibility. Existing practice templates for Quiz, Listening, Fill, Matching and Speaking are still retained under `templates/`.

TOEIC questions are managed through the Admin TOEIC Question Bank in this release; there is no bulk TOEIC-question CSV importer yet.
