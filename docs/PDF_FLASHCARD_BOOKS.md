## Learning model

1. Read/listen in **Học liệu TOEIC 800+** to understand the source lesson.
2. Open **Bộ Flashcard TOEIC** and create the relevant personal book once.
3. Use Flip, VI→EN Active Recall, Cloze and Audio First.
4. Rate cards with the existing SRS; weak cards return earlier.
5. The generated set is user-owned and lives under **Bộ Flashcard TOEIC 800+**.

The release does not interpret every English word appearing in explanatory prose as a vocabulary card. It converts the source's explicit vocabulary/verb/chunk lists and memorization-oriented grammar structures. This avoids invented meanings and low-value duplicate cards.

## Upgrade safety

Migration 014 changes no schema and deletes no user data. It only renames an already-installed legacy combined Verb Master set to **TOEIC Verb Master 800+ – Tổng hợp (bản cũ)**. New section books use new `source_type` values, while existing card IDs and SRS rows remain untouched.
